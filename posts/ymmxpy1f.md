考虑从 $(0, 0)$ 到 $(n, m)$，每次可以向右或向上，有多少种路径？

显然有 $P(n, m) = \dbinom{n + m}{n}$ 种。

如果要求不能触碰 $y = x + b$ 这条直线呢？

考虑计数碰到直线的路径数，我们将一条碰到的路径在第一次碰到的位置后对 $y = x + b$ 对折，则终点为 $(n, m)$ 关于 $y = x + b$ 的对称点 $(m - b, n + b)$。

所以方案数 $P(n, m) - P(m - b, n + b)$。

若有两条线 $y = x + b, y = x + c$ 呢？

这里只考虑终点在两条线中间的情况，其余情况等价于一条线。

令两条直线分别为 $A, B$。

于是我们可直接容斥计算，令 $ABAB$ 表示钦定依次经过 $A, B, A, B$ 的路径数量，连续多次经过只算一次。

则路径数为 $\empty - A - B + AB + BA - ABA + BAB - \dots$。

按照先经过 $A$ 还是 $B$ 分成两类，每类可以依次将终点关于两条直线翻转，知道翻转出第一象限。

每两次翻转，必然使坐标减少 $|b - c|$，所以时间复杂度 $O(\dfrac {n + m}{|b - c|})$。

利用这个东西可以推卡特兰数。

卡特兰数的一个定义是 $n$ 个点的有根有序树数目，等价于 $n$ 对括号的合法括号序列数目。

转化为 +1-1 序列，在坐标系上旋转 $45$ 度，即为不能经过 $y = x$，从 $(0, 1)$ 到 $(n - 1, n)$ 的方案数。
