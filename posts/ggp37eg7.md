$f(n) = \oplus_{i = 1}^n i$。

1. $n = 4k$，$f(n) = n$。
2. $n = 4k + 1$，$f(n) = 1$。
3. $n = 4k + 2$，$f(n) = n + 1$。
4. $n = 4k + 3$，$f(n) = 0$。
