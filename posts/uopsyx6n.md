T3 的难点全在第一步转化了。

令 $b_i = [a_i = a_{i + k}], i \leq n - k$。

原题转化为求 $b$ 的数量满足不存在连续 $k$ 个 $1$。

之后的过程就中规中矩了，边推边写代码验证还是可以的。

枚举 $p$ 表示 $b$ 中的 $0$ 个数。

考虑 $1$ 的限制，有 $n - k - p$ 个 $1$，我们考虑用 $p$ 个 $0$ 将其分割成 $p + 1$ 份。

每一份的 $1$ 数量为 $0 \leq x_i < k, \sum_{i = 1}^{p + 1} x_i = n - k - p$。

求其方案数。

考虑容斥，假设有 $q$ 个 $x_i \geq k$ 其余无限制，我们将这 $q$ 个减去 $k$，$x'_i \leftarrow x_i - k$，则问题变成 $\sum x'_i = n - (q + 1)k - p$ 的无限制情况。

故总方案为 $\sum_{q = 0}^{p + 1} (-1)^q \dbinom{n - (q + 1) k}{p} \dbinom{p + 1}{q}$

答案为 $m^k \sum_{p = 0}^{n - k} (m - 1)^p \sum_{q = 0}^{p + 1} (-1)^q \dbinom{n - (q + 1) k}{p} \dbinom{p + 1}{q}$。

考虑化简：
$$
\sum_{q = 0}^{p + 1} (-1)^q \dbinom{n - (q + 1) k}{p} \dbinom{p + 1}{q}
\\
= \sum_{q = 0}^{p + 1} (-1)^q \dbinom{n - (q + 1) k}{p} (\dbinom{p}{q} + \dbinom{p}{q - 1})
$$

分开计算：

第一部分

$$
\sum_{p = 0}^{n - k} (m - 1)^p\sum_{q = 0}^{p + 1} (-1)^q \dbinom{n - (q + 1) k}{p} \dbinom{p}{q}
\\
= \sum_{p = 0}^{n - k} (m - 1)^p \sum_{q = 0}^{p + 1} (-1)^q \dbinom{n - (q + 1) k}{q} \dbinom{n - (q + 1) k - q}{p - q}
\\
= \sum_{q = 0}^{n - k + 1} (-1)^q \dbinom{n - (q + 1)k}{q} \sum_{p = q - 1}^{n - k} (m - 1)^p \dbinom{n - (q + 1) k - q}{p - q}
\\
= \sum_{q = 0}^{n - k + 1} (-1)^q \dbinom{n - (q + 1)k}{q} \sum_{p = 0}^{n - k - q} (m - 1)^{p + q} \dbinom{n - k - q - kq}{p}
\\
= \sum_{q = 0}^{n - k + 1} (-1)^q \dbinom{n - (q + 1)k}{q} (m - 1)^q m^{n - q - k(q + 1)}
$$

由于 $k (q + 1) \leq n$，对于 $k \leq n$，枚举次数为 $\sum_i \dfrac 1i = O(n \log n)$。

第二部分
$$
\sum_{p = 0}^{n - k} (m - 1)^p\sum_{q = 1}^{p + 1} (-1)^q \dbinom{n - (q + 1) k}{p} \dbinom{p}{q - 1}
\\
= \sum_{p = 0}^{n - k} (m - 1)^p\sum_{q = 1}^{p + 1} (-1)^q \dbinom{n - (q + 1) k}{q - 1} \dbinom{n - (q + 1) k - q + 1}{p - q + 1}
\\
= \sum_{q = 1}^{n - k + 1} (-1)^q \dbinom{n - (q + 1) k}{q - 1} \sum_{p = q - 1}^{n - k} (m - 1)^p \dbinom{n - (q + 1) k - q + 1}{p - q + 1}
\\
= \sum_{q = 1}^{n - k + 1} (-1)^q \dbinom{n - (q + 1) k}{q - 1} \sum_{p = 0}^{n - k - q + 1} (m - 1)^{p + q - 1} \dbinom{n - (q + 1) k - q + 1}{p}
\\
= \sum_{q = 1}^{n - k + 1} (-1)^q \dbinom{n - (q + 1) k}{q - 1} (m - 1)^{q - 1} \sum_{p = 0}^{n - (q + 1) k - q + 1} (m - 1)^p \dbinom{n - (q + 1) k - q + 1}{p}
\\
= \sum_{q = 1}^{n - k + 1} (-1)^q \dbinom{n - (q + 1) k}{q - 1} (m - 1)^{q - 1} m^{n - (q + 1) k - q + 1}
$$

同上，$O(n \log n)$。

综上，答案为 $\sum_{q = 1}^{n - k + 1} (-1)^q \dbinom{n - (q + 1) k}{q - 1} (m - 1)^{q - 1} m^{n - (q + 1) k - q + 1} + \sum_{q = 0}^{n - k + 1} (-1)^q \dbinom{n - (q + 1)k}{q} (m - 1)^q m^{n - q - k(q + 1)}$。

T4 先排序，分成两部分，分开 dp，$O(3^{\frac n2})$。

然后对于跨过两部分的，考虑右边，因为排序后右边单价高，所以右边决定代价。

所以枚举右侧，再枚举其子集，子集表示本次跨过的部分，可以算出其单价，在枚举做部分的所有情况，可以先都按体积排序，用双指针算出左部分的子集，合并即可。

实现有些细节，但还好。

总时间复杂度是神秘的 $O(6^{\frac n2})$，$n \le 22$。
