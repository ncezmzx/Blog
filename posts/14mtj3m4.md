$100 + 20 + 40 + 0 = 160$，T2 居然还挂了 $10$ 分。

鉴定为：不会 dp 导致的。

T1 枚举，然后死磕 T2，观察到一个性质：每个数最多有 $16$ 个不同的质因子。然后就一直在这个 $16$ 里面出不来了。。。又想办法容斥，结果好不容易想到发现时间炸了。

于是去开了 T3，读完以为是简单题，直接开写哈希 + dp，然后大样例假了，改掉了一个锅之后发现无论怎么调都是比答案小，于是放弃回去蹬 T2。

然后 T2 始终没蹬出那个关键的性质，一直在那个没用的 $16$ 旁边徘徊，最后只好写个暴力结果还挂了 $10$ 分。

T3 没啥头绪，换成字典树还是比答案小，于是直接交了，后来想到了可以在字典树上 dp。但是时间不够了，于是在没有想清楚的情况下，直接开写，写了 $4,5$ 个不同版本的 dp，觉得没有时间仔细思考了，于是疯狂的改转移改边界，比答案小就加上点东西，比答案大就直接把非结尾的节点的 dp 值直接赋为 $0$。

改来改去，改出了一个能过大样例的，一测小样例 $1$，比答案大好多，下班。

T1 枚举，T2 结论 + 状压 dp，T3 字典树上做树形 dp，T4 线段树哈希优化 dp。

dp 写不了一点啊，我也就会写写数据结构、数位 dp 和区间 dp 之类的板子吧
