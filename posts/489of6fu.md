> 给定 $n$，构造一条链，每个点有点权 $\le 11000$，使得对于 $\forall 1\le k \le n$，存在一条路径其点权 $\gcd = k$，$n\le 2500$。

很巧妙的题。

先引入 n-smooth 数：
- 若一个数 $x$，其最大素因子 $\le n$，则称这个数为 n-smooth 数。


于是我们考虑将 $k$ 表示为 3-smooth 数乘上一个 $v$，$k=2^p3^qv$。

于是我们可以按 $v$ 对 $k$ 划分等价类，对于每个等价类，我们的 $\gcd$ 只要能凑出所有 $\le \frac nv$ 的 3-smooth 数即可。

假设 $n = 15v$，列一个表：

$$
\begin{matrix}
1v & 2v & 4v & 8v & \textbf{16v}\\
3v & 6v & 12v & \textbf{24v}\\
9v & \textbf{18v} & \textbf{36v}\\
\textbf{27v}
\end{matrix}
$$

注意到，加粗的位置圈出来的上三角是我们要构造的。

容易观察到，直接选加粗位置即可，因为对于每个我们要构造的数，我们找到其所在行和列的加粗位置，这两数构成的区间 $\gcd$ 即为我们要的数。

注意到每列有且只有一个位置，故需要 $\lfloor \log_2(\frac nv)\rfloor + 2$ 个点。

总点数：

$$
\begin{aligned}
& \sum_{\gcd(v, 6) = 1} \lfloor \log_2(\frac nv)\rfloor + 2\\
= & \sum_{\gcd(v, 6) = 1} \sum_{k \ge 0} [2^kv \le n] + 1\\
= & \sum_{v = 1}^n [\gcd(v, 6) = 1] + [3\nmid v]
\end{aligned}
$$

容易发现 $[\gcd(v, 6) = 1] + [3\nmid v]$ 存在长度为 $6$ 的循环节，当 $n\equiv 1, 2, 5\pmod 6$ 时，点数为 $n +1$，其余为 $n$。

考虑优化，我们注意到对于 $2v > n$ 的数，我们要两个点 $2v, 3v$，这样显然不优，考虑合并 $2u > n, 2v > n$，我们可以构造 $u, \mathrm{lcm}(u, v), v$ 三个点的链，这样就把点数控制在 $\le n$ 了。

但是点权大小有限制，我们枚举一下找出 $\mathrm{lcm}(u, v)\le 11000$ 的合并即可。

注意到 $n = 5$ 时，满足 $\gcd(v, 6) = 1, 2v >n$ 的只有一个 $5$，没法合并，搜一个方案，特判一下即可。

$O(n^2)$。

```cpp
#include <bits/stdc++.h>
using namespace std;
constexpr int N = 2509;
int n, a[N];
signed main() {
#ifndef LOCAL
  freopen("divisors.in", "r", stdin);
  freopen("divisors.out", "w", stdout);
#endif
  cin.tie(nullptr)->sync_with_stdio(false);
  cin >> n;
  if (n == 5) return cout << "10 15 6 8 4\n1 2\n2 3\n3 4\n4 5", 0;
  set<int> u;
  int rem = n;
  for (int v = 1; v <= n; ++v) {
    if (v % 3 == 0 || v % 2 == 0) continue;
    if (2 * v > n) {
      u.insert(v);
      continue;
    }
    int k = 0;
    while ((1 << k) * v <= n) {
      int s = 1;
      while (s * (1 << k) * v <= n) s *= 3;
      cout << s * (1 << k) * v << ' ', ++k, --rem;
    }
    cout << (1 << k) * v << ' ', --rem;
  }
  if (u.size() > 1) {
    bool ok = false;
    for (int i : u) {
      for (int j : u) {
        if (i != j && i * j / __gcd(i, j) <= 10000) {
          cout << i << ' ' << i * j / __gcd(i, j) << ' ' << j << ' ';
          u.erase(i), u.erase(j), ok = true;
          break;
        }
      }
      if (ok) break;
    }
    assert(ok);
    rem -= 3;
  }
  for (int v : u) {
    int k = 0;
    while ((1 << k) * v <= n) {
      int s = 1;
      while (s * (1 << k) * v <= n) s *= 3;
      cout << s * (1 << k) * v << ' ', ++k, --rem;
    }
    cout << (1 << k) * v << ' ', --rem;
  }
  while (rem--) cout << 1 << ' ';
  cout << '\n';
  for (int i = 1; i < n; ++i) cout << i << ' ' << i + 1 << '\n';
}
```
